# Translating National Parks (`text/`)

Every string a player sees in National Parks is a `LOC_*` tag defined here and looked up by the game at run time. The
scripts set no display text of their own, so a translation needs no code change: add the language's files here and
two lines per file to the modinfo.

## Files

| File | Contents |
| --- | --- |
| `en_us/ModuleText.xml` | The source of truth for the game text: the mod's name and description, the improvements, projects, picker, buttons, questions, notices, park names, the lens, Options and the pop-up quotes. |
| `en_us/PediaText.xml` | The Civilopedia: the "National Parks" section and the Parks and Wilderness pages under Game Concepts (192 tags). Generated by `devtools/gen-pedia.py`; to change the English, edit the script and run it from the mod folder. |

All eleven languages below ship as machine translations (2026-10-01) that use the game's own words for its terms,
taken from the game's l10n files by `devtools/gen-glossary.py` into `devtools/glossary/` (generated locally, not
committed; run the script to rebuild it). To correct one, edit its `<Text>`; to change the English, edit the English
and update every language. `node devtools/check-locale.mjs <folder>` checks a single folder.

## Two file shapes

English uses an `EnglishText` block with `Row`:

```xml
<Database>
    <EnglishText>
        <Row Tag="LOC_WA_NAME_FORMAT"><Text>{1_Name} Wilderness Area</Text></Row>
    </EnglishText>
</Database>
```

Every other language uses a `LocalizedText` block with `Replace` and a `Language` attribute:

```xml
<Database>
    <LocalizedText>
        <Replace Tag="LOC_WA_NAME_FORMAT" Language="de_DE"><Text>Wildnisgebiet {1_Name}</Text></Replace>
    </LocalizedText>
</Database>
```

**The `Language` value is not the folder name.** Use these exactly (note `zh_cn`):

| Folder | `Language=` | Folder | `Language=` |
| --- | --- | --- | --- |
| `de_de` | `de_DE` | `pl_pl` | `pl_PL` |
| `es_es` | `es_ES` | `pt_br` | `pt_BR` |
| `fr_fr` | `fr_FR` | `ru_ru` | `ru_RU` |
| `it_it` | `it_IT` | `zh_cn` | `zh_Hans_CN` |
| `ja_jp` | `ja_JP` | `ko_kr` | `ko_KR` |
| `zh_hk` | `zh_Hant_HK` (Traditional Chinese) | | |

## Registering a language in the modinfo

Each file is listed once per action group that loads text, with a `locale` attribute. In `national-parks.modinfo`,
the shell group loads the game text (for the Additional Content list and Options in the main menu) and both age
groups load the game text and the Civilopedia. For German:

```xml
<!-- national-park-shell, under <UpdateText> -->
<Item locale="de_DE">text/de_de/ModuleText.xml</Item>

<!-- national-park-exploration and national-park-modern, under <UpdateText> -->
<Item locale="de_DE">text/de_de/ModuleText.xml</Item>
<Item locale="de_DE">text/de_de/PediaText.xml</Item>
```

## Rules

- **Every tag, in every language.** Each language must hold exactly the English tags. The game loads one language at
  a time, so a tag missing from a translation shows as the raw `LOC_...` key to that language's players.
  English text may stand in for a line not yet translated.
- **Keep the placeholders and icons.** `{1_Name}`, `{1_Count}`, `{1_Price}` and the like are filled in by the game;
  keep each one, in whatever position the language needs. Plural forms such as
  `{1_Count: plural 1?tile; other?tiles;}` use the game's ICU plural syntax: translate the words inside and add the
  plural categories the language needs. Keep every `[icon:YIELD_...]` tag.
- **Keep the markup.** `[B]...[/B]` is bold; `[BLIST][LI]...[LI]...[/LIST]` is a bulleted list.
- **Park names.** `LOC_NP_PARK_NAME_FORMAT` and `LOC_WA_NAME_FORMAT` build a park's name from a place name
  (`{1_Name}`), and `LOC_NP_PARK_NAME_ORDINAL` adds a Roman numeral when a name is taken. A park is named once, when
  it is founded, in the language the game is in then; switching language later keeps the names already given.
- **Page titles stay short.** The Civilopedia sidebar cuts titles longer than about 24 characters.
- **No duplicate tags.** A tag defined twice in one file makes the game drop the whole file.

## Checking a translation

`npm run verify` (`tests/i18n.test.mjs`) fails when a translation is missing a tag or has an extra one, uses the
wrong `Language`, uses `Row` instead of `Replace`, defines a tag twice, or drops a placeholder or icon that the
English has. It also checks that every key the mod uses has English text.

## The quotes

The 33 `LOC_NP_QUOTE_*` rows hold quotes by naturalists for the pop-ups, each the whole display line. They are the
same English text in every language: the quotes are English originals, and a version in another language would need a
named published translation. Where each was read is in `docs/quote-sources.md`.
